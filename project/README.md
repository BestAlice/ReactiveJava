# KAST

## Как запустить
1. В папке `frontend` прописать следующие команды:
   - `npm install`;
   - `npm run dev`.
2. В папке `backend/backend-docker` запустить `docker-compose.yml`, прописав команду: `docker compose -f docker-compose.yml up --build -d`.
3. Запустить Java-проект, расположенный в папке `backend`.
